# Live demo: current RofR and the proposed replacement

A 5–10 minute walkthrough for the session host. You narrate; the board watches. Do not collect scores. After this, give them the acceptance page and let them try it themselves.

Have both sites open in two windows before the room sits down:

- Current RofR: <http://rofr.ivoa.net>
- Proposed replacement: <https://benson.kawfee.ca>

Use the same publishing registry address you will give them for question 4 on the acceptance page.

## Before the room sits down

- Confirm both sites load.
- Confirm the chosen registry address still responds (open it with `verb=Identify` in a tab).
- Do not use a registry you care about listing. The board may optionally register after their own try.
- If validation is usually slow, say up front: this step can take a few minutes; watching it start is enough.

## Run of show

### 1. Same job (1 minute)

Home pages side by side. Say: both list searchable registries, list publishing registries, and let you validate a registry before listing it. The new site is a proposed replacement.

### 2. Searchable list (1 minute)

On the current site, follow the link to the list of full searchable registries. On the new site, click **Full searchable registries** if the list is folded away. Name one entry on each side.

### 3. Publishing list (1 minute)

Same for **Currently registered publishing registries**. Point at one identifier so it is clear this is a catalogue of registries, not a search engine for astronomers.

### 4. Dry-run validate (3–5 minutes)

On the new site, click **Register / validate a registry**. Paste the host address. Click **Validate (dry run)** and wait.

A pass or a fail both count. Do not register.

If nothing returns in about two minutes, say so and move on. The board will try this themselves.

### 5. Handoff (30 seconds)

Give them the acceptance page and the registry address. Their verdict is what matters.
