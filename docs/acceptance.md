# Trying a new Registry of Registries

The Registry of Registries (RofR) lists the publishing registries that make Virtual Observatory resources findable worldwide. We are considering a replacement for the current site.

Please open both of these in your browser:

- Current RofR: <http://rofr.ivoa.net>
- Proposed replacement: <https://benson.kawfee.ca>

This should take about 20–30 minutes. After a successful validation you may register if you want to see the full path. That is optional. Trial listings can be taken down later.

The session host will give you one publishing registry address to use in question 4.
